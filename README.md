# Faisal Cosmetics Store
Customer e-commerce website + separate admin panel + MongoDB backend.

Requirements: Node.js 18+ and MongoDB.

Run:
1. npm install
2. Copy .env.example to .env
3. Start MongoDB
4. npm start
5. Customer: http://localhost:5000/
6. Admin: http://localhost:5000/admin/

Default admin: admin / admin123. Change it in .env before deployment.
